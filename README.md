# Desktop Tube

A tiny Android app that opens YouTube in a WebView that always identifies as a desktop browser
(same as ticking "Desktop site"). YouTube links open in the app.

Download the latest APK from the Releases page and install it (allow "install unknown apps").

Note: whether audio keeps playing with the screen off depends on your Android version and
YouTube's current behavior; it is not guaranteed. YouTube Premium is the supported way to get it.
